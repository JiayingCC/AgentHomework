AN AGENTIC-WORKFLOW HOMEWORK PROJECT

Behind the ink.

A small website. A record of the choices that shaped it.

From a broad idea to one usable journey.

The first idea included games, a brush simulator, couplets, red envelopes, and a gallery. A rubric review led to a smaller first release: one character, one game, and a keepsake you can actually save.

  1. 01

    Brief & direction

    The student chose calligraphy, then changed the visual direction from pastel colors to minimal fluid glass.

  2. 02

    Research & build

    The coding agent checked references, selected reusable stroke data, and built the lesson, drawing tools, and collection.

  3. 03

    Check & iterate

    Software checks and browser interaction test drawing, saving, and export. A three-person learner trial is still planned; no participant results are claimed.

This page records agent-assisted development. The website itself runs locally in your browser and does not call an AI service.

TRY YOUR NEXT ITERATION

Give the agent a useful brief.

Prompt

The task you give an agent, including the outcome, constraints, and checks.

Context

The brief, code, sources, and prior decisions the agent needs to work well.

Tool

An action the agent can take, such as reading a source, editing a file, or checking a browser.

Handoff

Passing a bounded result, such as a source sheet, into the next task.

Evaluation

Checking an output against concrete expectations instead of assuming it works.

Iteration

Changing something based on a finding, then checking the result again.
