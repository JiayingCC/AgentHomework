# Mindplay design direction

Audience: curious students learning introductory psychology and agent workflows. Primary task: play a short experiment, understand the result, then inspect how the website was made.

Palette: cloud #f5f2fa, ink #302b46, lilac #ddd0f7, grape #72609b, peach #f8d8c7, mint #d6ece2. Color-game stimulus colors are separate high-contrast tokens on solid white.

Typography: Avenir Next/system sans for body, Trebuchet MS for rounded display type, Georgia italic for a small warm accent. Local font stacks keep the prototype dependency-free.

Signature: a translucent, smiling three-petal mind sculpture surrounded by floating concept labels. It is an original SVG interface illustration. Fine procedural grain and pastel light pools give panels a frosted surface. Solid-background preference and reduced-motion support preserve usability.

Layout: quiet top navigation; functional hero with direct play button; three game cards; real local progress; agent-studio doorway. Knowledge garden and Agent studio use in-page hash navigation, so GitHub Pages needs no router fallback.

Design critique: a generic glass dashboard would bury the activity under metrics. This design keeps games central and limits metrics to completed activities and participation XP. No invented streaks, player counts, or performance ranks.

References consulted:
- Apple Liquid Glass: https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass (layering, hierarchy, restrained materials).
- Nielsen Norman Group: https://www.nngroup.com/articles/glassmorphism/ (readability, strong blur, optional solid surfaces).
- Duolingo design: https://blog.duolingo.com/hub/design/ (playful learning interface reference).
- Awwwards interactive collection: https://www.awwwards.com/websites/web-interactive/ (interactive site reference).

References inform principles; their artwork and layouts are not copied.
