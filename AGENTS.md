# Working in this repository

- Read the relevant assignment brief and success criteria before making changes.
- Keep assignment-specific code and dependencies in that assignment's folder.
- Prefer small, understandable changes; explain decisions that affect the result.
- Use the assignment's chosen language and tools. Do not introduce a framework before one is needed.
- Run checks appropriate to the change. State what ran, what passed, and what remains unverified.
- Record useful observations in the assignment write-up or an experiment log.
- Never commit credentials, API keys, private datasets, dependency folders, or generated caches.
- Preserve existing user work and follow the course's rules for AI assistance.
